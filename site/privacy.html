Privacy

Privacy at RepoContext

RepoContext is a local, read-only MCP server. The public website has no accounts, forms, or client configuration collection.

Product telemetry

The CLI and MCP transports do not send telemetry.

RepoContext never sends repository contents, filesystem paths, Git history, questions, MCP requests, answers, citations, registry configuration, or tokens to the website analytics service.

Optional website analytics

The site is built with analytics disabled unless its operator configures a dedicated RepoContext PostHog project. When enabled, collection is cookieless and limited to page views, a small set of link clicks, and the audience-selector choice. Autocapture, session replay, and person profiles are disabled.

Security and contact

To report a vulnerability, follow the security policy. For public product questions or corrections, use the issue tracker.
