# Execution Plans

Complex, multi-session work gets a resumable plan here. Completed plans move to
`docs/plans/completed/`. A plan records: purpose, verified current behavior, target
behavior, progress, discoveries, decisions, milestones with validation, risks, and
final evidence.

  `docs/compare.md`.
